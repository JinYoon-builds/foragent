# Rules in force

This file lists the rules in force now, one line each. Each line cites a live decision in
[decisions.md](decisions.md), which keeps the history and the reasons. Only Jin makes rules ([D108](decisions.md#d108-지금-규칙은-rulesmd-지난-기록은-decisionsmd-2026-10-31-jin)).
Each line ends with `Check:` and the tests that keep it true, or `Check: people only.` when no code
enforces it. `tests/acceptance/test_rules_checked.py` fails when a line names no check or a test that
does not exist, so a change that removes or renames a named test updates the line too.

## When to ask the person

- Ask the person only about goal changes, trade-offs, taste, hard-to-undo actions, and scope or priority. Hard to undo means data, money, public exposure or sending to others; changes git can revert, including deleting superseded code, are not person questions. A question an existing decision answers goes to the PM, not the person. Do anything with a right answer, then report it. ([D71](decisions.md#d71-사람에게-묻는-기준-정답이-있는-일은-하고-알린다-2026-10-22-jin), [D115](decisions.md#d115-대체된-코드를-지울지는-사람에게-묻지-않는다-2026-11-04-jin)) Check: `tests/acceptance/test_orch_ask_rule.py::test_orch_ask_rule_limits_questions_to_d71_human_choices`, `tests/acceptance/test_orch_ask_rule.py::test_orch_ask_rule_answerable_repairs_are_done_then_reported_with_record`.
- Decisions made with the person go into decisions.md and this file in the same session; memory keeps only a link. ([D114](decisions.md#d114-사람의-결정은-저장소에-바로-넣는다-2026-11-04-jin)) Check: `tests/acceptance/test_decisions_stop_check.py::test_the_stop_hook_blocks_once_with_the_count_and_the_oldest_age`.

Lists come only on request (`fa brief --report --full`), and each decision is asked as its own multiple-choice question, recommendation first. ([D127](decisions.md#d127-fa-보고는-세-줄이다-2026-11-05-jin)) Check: `tests/acceptance/test_fa_short_report.py::test_report_is_at_most_three_lines_plus_the_update_line`, `tests/acceptance/test_fa_short_report.py::test_no_line_lists_merges_holds_questions_or_options`.

- Telling the person to type a command is a failure signal. Foragent runs it.
