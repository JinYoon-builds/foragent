# Split cli.py into discovered command modules

Evidence (2026-10-25): nearly every issue declares src/foragent/cli.py (864 lines, about 70 add_parser calls), so the gate's file-overlap rule kept unrelated issues waiting while run slots sat idle (#108 waited on #412/#419). Same remedy as messages/ and watch_sections/ (#352, #353). D88: this cuts waiting.

- Each top-level `fa` command group lives in its own module under `foragent.commands`, found by discovery; cli.py builds the parser from them and stays small.
- A new group needs no edit to cli.py.
- Every name importable and patchable from foragent.cli today stays so; `fa --help` lists the same commands; the 61 CLI acceptance files that pass today keep passing.
