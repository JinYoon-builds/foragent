# D73 addendum: research packs per medium

Web (Mobbin, Godly, Awwwards; widths, accessibility, dark mode), mobile (Mobbin, Apple HIG, Material; platform conventions, touch size), terminal UI (lazygit, btop, k9s, Bubble Tea, Ratatui; ambiguous-width glyphs like ◀ in Korean fonts, minimum widths 44/56, alternate screen, wheel vs click, no-colour terminals), pixel art (Lospec palettes; half-block resolution, dark outlines vanish on dark backgrounds → dark brown), plain CLI output (strip colour when piped, long lines). Packs ship in skills/fa-design-session/media/; lessons that recur across projects accumulate in ~/.local/share/foragent/media/ (D75).
