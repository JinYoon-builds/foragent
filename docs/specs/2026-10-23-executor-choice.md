# D74: choose the executor per issue

Headroom = remaining quota ÷ hours until reset (most constraining window; Claude measured against the keep-share cap). The larger headroom implements; the other reviews. One issue keeps its executor for all attempts; only on hitting the limit does it hand over with a summary. A lane with `executor:` set stays fixed. No usage recorded → configured default.
