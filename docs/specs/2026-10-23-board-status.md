# D31 addendum: board columns

The Projects board shows five columns: 🗂 Backlog (not approved) · 🌰 Up next (Approved, Ready) · 🐿 In progress (Running, PR open; Blocked with ⚠) · ✋ Your turn (Needs human) · 📦 Done. The gate's internal states stay; they are grouped only when written to the board. A repository with an existing board maps the five groups to that team's columns (asked once in init; changed later in the settings window's team tab). Cards move only when the column actually changes.
