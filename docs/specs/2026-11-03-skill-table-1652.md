# #1652: permissive notices and Jin's role defaults

Status: unapproved draft editing open issue #1652. Lane: `skills`. Size: `s`.
This order creates no issue and grants no approval.

## Goal

Make complete permissive licenses usable with attribution and source notices, then
give each role exactly Jin's default principles through the setting delivered by
#1619. Use the repository copies of the skills, with their notices intact.

A LICENSE passes when it contains a known permissive license text word for word
and its only other nonblank lines, before or after that text, are:

- `SPDX-License-Identifier` lines naming a permissive license;
- copyright lines;
- attribution or source lines;
- URL lines.

Whitespace and copyright names retain #1619's treatment. Copyright names are
never judged. An extra condition, a prohibition, modified or incomplete terms,
or a nonpermissive declaration still fails. A standard license must be complete;
a permissive heading or SPDX marker cannot override extra terms. Preserve the
previously accepted SPDX-only form without broadening that form to arbitrary
notices without a complete license.

This applies equally to repository and imported skills. A repository name,
author, source host or installed location grants no exception. The shipped
three-line header plus MIT text passes without changing any LICENSE file.

Set `.foragent.yml`'s public `default_skills` table to these repository copies:

| Role | Skills, in order |
| --- | --- |
| workers, including issues with no lane | `principle-prove-it-works`, `principle-fix-root-causes`, `principle-attack-the-premise`, `principle-sequence-verifiable-units` |
| reviewers | `principle-prove-it-works` |
| orchestrator | `principle-prove-it-works`, `principle-attack-the-premise` |
| architect | `principle-attack-the-premise`, `principle-redesign-from-first-principles` |
| docs | none |

Each role's session input exposes readable guidance for exactly its assigned
default principles. Explicitly shared principles may reach each assigned role;
another role's exclusive defaults may not. No `docx`, `pdf`, `pptx` or `xlsx`
skill is assigned or automatically delivered to any role. The review procedure
stays out of this table until #1651 merges; this issue does not wait for #1651.

Keep #1619's remaining behavior: no symlink defaults, no copyleft,
non-commercial or source-available defaults, license decisions about the actual
copy, role isolation, no fallback between roles, safe setup and notice retention.
Keep its existing acceptance file unchanged. Two old unit-test inputs that
reject SPDX plus a complete permissive text are superseded by this rule; retain
them as positive regressions, with all unrelated checks preserved.
