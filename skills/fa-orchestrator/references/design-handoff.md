# Design handoff from planning

When visual direction is unresolved, suggest the design interview (디자인 인터뷰 in `/fa`, the
`fa-design-session` skill) as design mode in the planning session; keep the conversation there
while references and running drafts are compared.

Read design requests recorded by `fa orch request` and the referenced
`docs/design/<topic>/HANDOFF.md` before preparing the order. Turn its selected draft, principles and
run instructions into lane issues, with visual Done when evidence of the same screen as the draft
(recorded viewport/terminal size and interaction states) alongside functional checks. Use the normal
single order approval card; a design handoff or request alone does not approve implementation.
