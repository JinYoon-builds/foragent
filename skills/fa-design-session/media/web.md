# Web research pack

## References

- Mobbin: real product screens and flows, searchable by pattern.
- Godly and Awwwards: bold, expressive sites for stretching an axis.
- Neighbouring fields: editorial print layout, posters, dashboards in games.

Save the link and a short note per reference. Do not commit screenshots.

## Pitfalls

- Screen widths: check narrow (360px), medium and wide layouts; nothing may
  overflow horizontally.
- Accessibility: contrast, keyboard focus order, visible focus, labels for
  icons, reduced motion.
- Dark mode: check both themes; colours that work on white can vanish on dark.
- Loading, empty and error states, not only the happy path.
