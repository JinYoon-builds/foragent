# Web research pack

## References

Look at [Mobbin](https://mobbin.com/), [Godly](https://godly.website/) and
[Awwwards](https://www.awwwards.com/) for contrasting layout, type and motion.
Include real product screens as well as showcase pages so the board reflects
the user's task. Borrow a direction from neighbouring print or object design
to widen the comparison. Return original source links and notes on what fits;
keep any reference screenshots local.

## Pitfalls

- Try the actual content at narrow, medium and wide viewport widths; inspect
  wrapping, overflow and dense or empty states.
- Check keyboard navigation, visible focus, readable contrast and reduced motion.
  Do not rely on colour alone to distinguish state.
- Inspect light and dark mode, including images, borders and disabled controls.
  A striking landing page may not support repeated work or long reading.

Use these checks when comparing running drafts, and put relevant constraints
in the handoff.
