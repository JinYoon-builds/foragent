# Mobile research pack

## References

Use [Mobbin](https://mobbin.com/) to compare real app flows, then consult
[Apple HIG](https://developer.apple.com/design/human-interface-guidelines/) or
[Material](https://m3.material.io/) for the target platform's conventions.
Compare navigation and interaction states, not just polished first screens.
Include a neighbouring field such as pocket guides or game menus to explore
different visual directions. Return links and notes; reference images stay local.

## Pitfalls

- Check platform navigation, back behaviour, gestures and safe areas rather
  than transferring desktop conventions unchanged.
- Check touch target size and spacing against the target platform's guidance;
  try one-handed use and avoid controls that require precise taps.
- Try small screens, larger text, long translations, keyboard appearance and
  scrolling. Check that focus and primary actions remain visible.
- A mobile-sized web draft can compare appearance; use a simulator or device
  for platform interactions that the browser cannot demonstrate.

Carry the chosen platform and relevant interaction checks into the handoff.
